# Quickstart & Validation: 入口頁與老師頁面對齊 OpenSpec 組

**Feature**: [spec.md](./spec.md) | **Contracts**: [contracts/](./contracts/)

## 前置需求

- 001、002 的設定與啟動方式（見 [README](../../README.md)），並已執行 `login-google`。
- 一份可以寫入的範例 B 副本（建議新建一份，避免舊答案影響寫回結果）。
- 同一台電腦、同一個瀏覽器，開啟多個**視窗或分頁**。

## 自動化測試

```bash
uv run pytest tests/integration/test_pages.py -v          # 頁面網址、導向、各頁只載入自己的程式（contracts/pages.md）
uv run pytest tests/integration/test_worksheet_api.py -v  # 學習單清單的 confirmed_at（contracts/api-changes.md）
uv run pytest                                              # 全部：001、002 的既有測試必須全部通過（SC-005）
```

## 人工驗證（驗收情境 E-01～E-10）

啟動伺服器：

```bash
uv run python -m guided_buzz
```

下面用「視窗 T」代表老師，「視窗 1、2」代表學生。

### V1：學生首頁（E-01、E-02）

1. 視窗 1 開啟 http://127.0.0.1:8000/ 。
   **預期**：看到「加入組別」、說明文字、組別代碼欄位，以及並排的「加入」「我是老師」；沒有密碼欄。
2. 輸入錯誤代碼 `AAAAAA` 並加入。**預期**：留在「加入組別」，顯示代碼錯誤的訊息。
3. （等 V3 建立活動後）輸入第一組的代碼並加入。
   **預期**：同一頁顯示第一組的作答畫面，網址仍是 `/`，「加入組別」與「我是老師」都消失。

### V2：老師入口（E-03、E-04）

1. 視窗 T 開啟 http://127.0.0.1:8000/ ，按「我是老師」。**預期**：網址變成 `/teacher`，只看到「老師登入」。
2. 輸入老師密碼登入。**預期**：
   - 網址仍是 `/teacher`。
   - 頁首只有「登出」。
   - 由上而下依序是：匯入學習單、已確認的學習單、建立搶答活動、目前活動、活動清單。
   - 畫面上沒有連到其他頁面的連結。

### V3：單一頁面完成整場活動（E-05、E-06）

1. 視窗 T 匯入範例 B 副本並按「確認」。**預期**：不必重新整理，「已確認的學習單」出現這份（含確認時間），建立活動的選單也能選到它。
2. 選這份學習單，組別輸入「第一組」「第二組」，建立活動。**預期**：「目前活動」顯示準備中與兩組代碼；「活動清單」多一列。
3. 視窗 1、2 在首頁分別以第一組、第二組代碼加入（V1 第 3 步）。視窗 T 按「開始搶答」。
4. 第一組送出題組 1，第二組送出第 5 題。視窗 T 對題組 1 按「判定無效」→「確定判定無效」，再按「結束搶答」。
5. **預期**：「目前活動」出現「寫回答案」「下載 CSV」。按「寫回答案」，顯示已填、未填的題號。
   到 Google Sheets 確認第 5 題的格子已經寫入；題組 1 因為被判無效，而且沒有下一順位，所以不會寫入。
6. 按「下載 CSV」。**預期**：下載檔案，畫面顯示筆數。
7. **全程**：視窗 T 的網址一直是 `/teacher`，沒有重新整理，也沒有輸入任何 ID。

### V4：活動清單（E-07）

1. 再建立一場活動，開始後立刻結束，不讓任何組送出。
2. 在「活動清單」按這場的「檢視」→「下載 CSV」。**預期**：顯示「此活動沒有任何送出紀錄」。
3. 按 V3 那場的「檢視」。**預期**：「目前活動」換成 V3 那場，可以再次寫回或下載。
   再次寫回時，已經寫入的格子會列為「跳過」。

### V5：多視窗身分與重新整理（E-08）

1. 視窗 T（已登入）、視窗 1（第一組）、視窗 2（第二組）各自重新整理。
2. **預期**：三個視窗都維持原本的身分與畫面，互不影響。

### V6：身分失效（E-09）

1. 建立新活動，讓視窗 1 加入第一組。視窗 T 按第一組的「重新產生代碼」。
   **預期**：視窗 1 回到「加入組別」，顯示代碼已重新產生的提示。
2. 讓視窗 2 加入一場準備中的活動，然後重新啟動伺服器（在終端機按 `Ctrl+C`，再執行一次啟動指令）。
   **預期**：視窗 2 回到「加入組別」，並顯示「活動已中斷，請老師重新建立。」；視窗 T 重新整理後回到「老師登入」。

### V7：舊網址（E-10）

1. 開啟 http://127.0.0.1:8000/student.html 。**預期**：網址變成 `/`，看到「加入組別」。
2. 開啟 http://127.0.0.1:8000/teacher.html 。**預期**：網址變成 `/teacher`。

### V8：登出（FR-021）

1. 視窗 T 按「登出」。**預期**：回到「老師登入」，網址維持 `/teacher`。
   伺服器 log 不再出現這個視窗重新連線的 `WebSocket /ws` 紀錄。
