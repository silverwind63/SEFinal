## 驗證中的發現與處理

1. **只有檢視權限的試算表可以匯入**：規格原本寫「沒有編輯權限 → 拒絕匯入」，實際上匯入只需讀取，Sheets API 在讀取時
   無法得知是否有編輯權限，所以會匯入成功，要到寫回時才被拒絕。已修正規格（US1 情境 5、6，US2 情境 5，Clarifications）
   與 quickstart V3 第 3 步。
2. **結構改變的訊息不夠直白**：插入一列後，已寫回的答案移到別列，訊息只說「第 12 列沒有填空格」。判斷正確，但老師不易
   聯想到原因。已改為先說明「學習單的結構和匯入時不同（例如插入或刪除了列）」，細節放在後面，並新增測試。
